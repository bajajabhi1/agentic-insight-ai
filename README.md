# Agentic Insight AI

A multi-agent AI research tool designed to discover and analyze businesses in the agentic AI space. 

## Features
- **Autonomous Discovery**: Find competitors and alternatives in the personal AI assistant market.
- **Deep Scraping**: Extract clean markdown from complex websites using Firecrawl.
- **Structured Analysis**: Use GPT-4o to categorize offerings, features, and pricing models.
- **Reporting**: Generate detailed comparison reports.

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Set your API keys in `main.py`.
3. Run the tool: `python main.py`
